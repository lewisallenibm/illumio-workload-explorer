Illumio Workload Explorer — Pilot

This pilot includes a private local PostgreSQL workspace. No database setup
is needed.

macOS package update

This release includes a packaging correction for the private PostgreSQL
workspace. It works correctly when macOS applies its unsigned-app protection.
Please use this replacement package rather than an earlier Mac pilot copy.

Testing status

The macOS package was tested directly. The Windows package was built and
verified on Windows, but needs a Windows user to open it and test the real
user experience.

Getting started

Open the Welcome tab for demo steps and import guidance. For the demo, load
mock Workloads, then mock CMDB data, then run Reconciliation.

Unsigned pilot notice
