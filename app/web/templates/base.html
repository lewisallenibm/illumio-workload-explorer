How it works

Start in Workloads to sync or import the Illumio view, then load or import the matching CMDB inventory. Use search, filters, bulk lookup, sorting, and pagination to find the systems you need. Finally, run Reconciliation to compare the two saved snapshots. In the background, PostgreSQL matches the records and highlights meaningful differences—such as labels that are missing or do not agree—so you can review and approve only the changes that matter.
